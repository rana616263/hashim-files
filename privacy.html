Privacy Policy

Last updated: 13 October 2026

Hashim Files is a personal tool that runs only on its owner's own computer. It is used only by its owner, with his own Google accounts.

What it accesses

When the owner connects a Google account, the app reads that account's email address, basic profile and Google Drive files and storage quota, so it can list, upload, preview and organise files in that Drive.

Where data is kept

Access tokens and the file list are stored, encrypted where possible, in a database on the owner's own computer. Files themselves stay in Google Drive. Nothing is sent to any other server.

Sharing

Google user data is not sold, shared with anyone, or used for advertising. Its use follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Use the developer email shown on the Google sign-in screen of this app.
